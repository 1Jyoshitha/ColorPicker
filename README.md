
# Color Picker App 🎨

A simple **ReactJS** application that allows users to pick colors from a color palette and see the selected color's hex code. This app is perfect for learning about React state management and handling user input events.

---

## 🔧 Features

- Select colors using a color picker.
- Display the hex code of the selected color.
- Dynamic UI updates as users select different colors.
- Responsive design for mobile and desktop.

---

## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js** and **npm** or **yarn** installed.

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/1Jyoshitha/ColorPicker.git
cd ColorPicker
```

2. **Install dependencies**
```bash
npm install
```

3. **Run the app**
```bash
npm start
```

The app will open at `http://localhost:3000`.
